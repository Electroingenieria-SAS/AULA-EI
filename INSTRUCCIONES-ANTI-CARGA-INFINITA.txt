AULA EI - PAQUETE CORREGIDO ANTI CARGA INFINITA

Sube el contenido de esta carpeta directamente a la raíz del repositorio Aula-EI-.
Debe quedar así:

Aula-EI-/
  index.html
  404.html
  .nojekyll
  favicon.svg
  assets/
    index-....js
    index-....css

Configuración recomendada en GitHub:
Settings > Pages > Deploy from a branch > main > / root

Correcciones incluidas:
1. El inicio de sesión ya no puede quedarse cargando indefinidamente.
2. Supabase tiene timeout de arranque de 7.5 segundos.
3. Si Supabase tarda, se libera la pantalla y se muestra login/diagnóstico.
4. Si falta un asset, el HTML muestra el recurso exacto que falló.
5. Se agregó favicon.svg para evitar 404 innecesario de icono.
6. Se agregó Cache-Control en index para disminuir caché viejo en primera carga.

Después de subirlo, usa Ctrl + F5 en el navegador.
