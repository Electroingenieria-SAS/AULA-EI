# Secret scan del paquete

Escaneo preventivo de patrones de secretos elevados en archivos entregables.

No se detectaron patrones de `sb_secret_`, PAT de GitHub, token de Vercel ni otros secretos elevados conocidos fuera de placeholders.

Nota: la publishable/anon key de Supabase puede estar presente en un frontend web por diseño; la seguridad depende de RLS y grants.
