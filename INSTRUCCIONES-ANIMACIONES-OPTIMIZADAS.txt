Aula EI — Animaciones optimizadas

Este paquete está compilado para GitHub Pages.

Reemplazar en la raíz del repositorio:
- index.html
- 404.html
- .nojekyll
- favicon.svg
- assets/
- brand/

Luego abrir con Ctrl + F5.

Cambios de rendimiento:
- Se eliminaron animaciones infinitas pesadas.
- Se redujeron blur, sombras y desplazamientos.
- Se quitó background-attachment: fixed para evitar tirones.
- Se redujeron delays y duraciones.
- Se conservó estética premium, pero con movimiento más rápido.
