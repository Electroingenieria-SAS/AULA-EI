AULA EI · ENTREGA TÉCNICA

Asistente de dominio

Guía el despliegue sin reemplazar GitHub ni Supabase. El flujo recomendado es GitHub → Vercel → dominio, manteniendo Supabase como base de datos, Auth, Storage y API.

1. Datos de la instalación

No guarda secretos
Nunca pegues aquí: service_role, sb_secret_..., contraseñas, tokens de GitHub/Vercel, claves privadas o credenciales del registrador. Esos secretos se configuran exclusivamente en los paneles oficiales o variables de entorno privadas.

2. Checklist guiado

0% completado

Comandos útiles

Clonar código fuente

git clone https://github.com/Electroingenieria-SAS/AULA-EI.git

Verificar paquete

npm run verify

Desplegar en Vercel

npx vercel@latest --prod
Supabase: no se “instala” dentro del hosting. Se mantiene como servicio externo y el frontend se conecta mediante URL + clave publicable, protegido por Auth/RLS.
  • Vercel: frontend/hosting.
  • GitHub: fuente y control de versiones.
  • Supabase: BD, Auth, Storage, RPC y Edge Functions.
  • Firebase: no detectado como dependencia activa en este paquete.

3. Configuración de dominio

El asistente no modifica DNS automáticamente porque los valores cambian según el dominio y el proveedor. La fuente válida es siempre la pantalla Domains del proyecto de Vercel.

4. Resumen para el administrador

Completa los datos y pulsa “Generar resumen de entrega”.

El progreso se guarda solo en el almacenamiento local del navegador. No se envía a ningún servidor.

Aula EI · Asistente técnico local · No contiene ni solicita secretos.
