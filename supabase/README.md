# Supabase

- `functions/`: Edge Functions con estructura desplegable. Incluye creación administrada y eliminación jerárquica de usuarios.
- `diagnostics/`: consultas de lectura y contrato del frontend.
- `migrations/`: reservado para migraciones nuevas, revisadas y ordenadas.
- `reference-sql/`: parches históricos recibidos; no representan el estado real ni un orden seguro de ejecución.

Antes de hacer soporte, lee [../docs/SUPABASE_SUPPORT.md](../docs/SUPABASE_SUPPORT.md).
